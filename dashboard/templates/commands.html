Command Directory

Complete listing of moderation, voice, security, and utility features.

🛡️ Security & Anti-Nuke

!lock — Locks text channel for @everyone
!unlock — Restores message permissions
!nuke — Clones and resets channel chat history
!autonuke set <min> — Sets auto-wipe interval timer
!mediaonly — Enforces attachment-only gallery mode

🔨 Moderation & Enforcement

!ban <user> [reason] — Permanent ban
!hardban <id> — Persistent blacklist with auto-reban
!jail <user> — Strips roles and locks user into #jail
!unjail <user> — Restores original roles
!strip <user> — Stores and removes all roles
!restore <user> — Restores archived roles

⚙️ Utilities & Info

!snipe / !cs — Views and clears deleted messages
!editsnipe — Shows original message before edit
!avatar / !banner — Retrieves profile artwork
!firstmessage — Jump link to the first channel message
!afk [reason] — Sets AFK status with auto-reply
